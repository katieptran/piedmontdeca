## About Us

Piedmont DECA is a student-led chapter exploring business, entrepreneurship, marketing, finance, and management. We build confidence, develop leadership skills, and connect through collaboration and competition.

## Membership Requirement

Students must be enrolled in **AP Business and Personal Finance** to join Piedmont DECA.

For information about joining, contact our chapter advisor, **Mr. Christensen**.

## Website

Our website is built with HTML, CSS, and JavaScript. All website code is contained in `index.html`; no installation or build step is required.

To preview the website, open `index.html` in a browser.

### Publish with GitHub Pages

1. Upload `index.html` to the root of this repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder.
5. Click **Save**.

Once deployment finishes, GitHub will display the website link in the Pages settings.
